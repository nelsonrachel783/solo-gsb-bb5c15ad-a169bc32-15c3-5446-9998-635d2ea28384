# SRT 字幕工具箱

一个网页小工具，包含两个功能（页面顶部标签页切换）：

1. **字幕时间校准**：根据若干「原字幕时刻 → 视频实际时刻」锚点，对整份 SRT 字幕做时间校准。
2. **剪辑片段字幕**：输入原 SRT 与按原视频时间填写的多个保留区间，预览并下载剪辑后 SRT。

- 后端：Python + FastAPI
- 前端：原生 HTML/JS 单页（无构建步骤）
- 校准算法：锚点按原时刻排序，相邻锚点间**线性插值**，首尾两端按**最近一段斜率外推**，统一换算每条字幕的起止时间
- 剪辑算法：以**左闭右开**区间求每条字幕与各保留区间的交集，空交集丢弃，跨区间字幕拆条，时间按「此前保留区间累计时长」重映射

## 启动

只需一条命令（依赖随容器自动安装）：

```bash
docker compose up --build
```

然后在浏览器打开：

**http://localhost:8000** （端口 `8000`；如需改端口，编辑 `docker-compose.yml` 的端口映射）

停止：`Ctrl+C` 或 `docker compose down`。

## 使用方法

### 功能一：字幕时间校准

1. **字幕内容**：粘贴 SRT 文本，或点击「选择文件」上传 `.srt` 文件。
2. **校准锚点**：至少填写 2 个锚点，格式为 `HH:MM:SS,mmm`：
   - 原时刻：字幕文件中显示的时间
   - 实际时刻：该句在视频中真实出现的时间
3. 点击 **预览校准结果**：表格逐条显示原时间、校准后时间及问题标记。
4. 若锚点校验失败（原时刻重复 / 实际时刻未严格递增 / 时间格式错误），页面会自动进行**异常定位**：
   - 标出建议剔除的最少锚点行，并用保留下来的锚点预览受影响字幕（仅建议，**确认前不改动输入**）；
   - 点击 **确认剔除并继续** 才会删除这些行并按原流程重新预览；点击 **放弃建议** 则原样保留输入；
   - 无法凑出 2 个有效锚点时提示「无法预演」，需手动修正。
5. 全部正常时点击 **导出校准后 SRT** 下载 `calibrated.srt`（保留原序号与正文）。

### 功能二：剪辑片段字幕

1. 顶部切换到 **剪辑片段字幕** 标签页。
2. **原字幕内容**：粘贴原 SRT，或上传 `.srt` 文件（两个标签页的输入相互独立）。
3. **保留区间**：按**原视频时间**填写多个 `起点 → 终点`（格式 `HH:MM:SS,mmm`）：
   - 起点必须**严格早于**终点；
   - 提交时自动按起点排序；
   - 区间**重叠会报错**（区间为左闭右开，前一区间终点等于后一区间起点的首尾相接是允许的）；
   - 起点终点都留空的行会被忽略，只填一个会报错；至少需要 1 个区间。
4. 点击 **预览剪辑结果**：表格显示每条结果的新序号、原序号、命中的输入区间行号、剪辑后时间与正文。
5. 点击 **下载剪辑后 SRT** 得到 `clipped.srt`。

**剪辑时间换算**：每段交集时间减去该区间起点，再加上此前所有保留区间的时长之和；结果按新起点排序，并从 1 开始连续重编号。例如保留区间为 `[00:00:00, 00:00:05)` 与 `[00:00:10, 00:00:20)`（按起点排序后），落在第二段开头的字幕 `00:00:10 --> 00:00:12` 会变为 `00:00:05 --> 00:00:07`；一条字幕若同时与两个区间相交（跨过被剪掉的片段），会拆成两条并保留同一份正文。

## 规则说明

### 锚点校验（不满足会被拒绝并提示）

- 至少 2 个锚点；
- 原时刻不得重复；
- 映射后的实际时刻必须严格递增。

### 锚点异常定位（剔除建议）

锚点校验失败时，后端按以下规则求一个修复方案：

1. 将锚点按**原时刻**排序，选出原时刻与实际时刻**都严格递增**的最长子序列（至少含 2 点），即需要剔除的锚点最少；
2. 多解时先最大化**首/尾原时刻**（全局最小、最大原时刻）锚点的保留数量；
3. 仍多解时，按待剔除项的**原输入行号序列**字典序最小决胜；
4. 无法解析的时间格式行必然在剔除之列；有效锚点不足 2 点则返回「无法预演」。

该逻辑由 `POST /api/suggest` 提供，返回剔除行号、逐行原因，并用保留锚点复用校准预览展示受影响字幕。

### 问题检测（存在任一问题时禁止导出）

| 问题 | 判定 |
| --- | --- |
| 负时间 | 校准后起点或终点 < 0 |
| 起止倒置 | 校准后终点 ≤ 起点 |
| 与下一条重叠 | 本条终点 > 下一条起点 |

前端预览会标红问题行，后端导出接口同样强制校验，有问题返回 400。

### 剪辑片段（保留区间校验与裁剪）

- 区间按**左闭右开** `[start, end)` 处理，时间均按**原视频时间**填写，格式 `HH:MM:SS,mmm`；
- 起点必须严格早于终点（`start < end`）；
- 提交后按起点排序（起点相同再按终点）；排序后相邻区间若 `后起点 < 前终点` 即判为**重叠并报错**，首尾相接（相等）允许；
- 对每条字幕 `[s, e)` 与每个保留区间求交集 `[max(s, start), min(e, end))`：交集为空（`cs >= ce`）则丢弃；
- 一条字幕与多个区间相交时**拆成多条**，每条保留同一份正文（含多行正文）；
- 第 k 段交集的新时间 = 交集时间 − 该区间起点 + 此前所有保留区间时长之和；
- 所有片段按新起点排序（终点兜底），从 1 开始**连续重编号**；全部无交集时导出空 SRT。

## API

- `POST /api/preview` — 请求体 `{"srt": "...", "anchors": [{"orig": "00:01:00,000", "actual": "00:01:02,500"}, ...]}`，返回逐条校准结果与问题标记。锚点校验失败返回 `400`，`detail` 为 `{"type": "anchor_invalid", "message": "..."}`。
- `POST /api/suggest` — 同请求体；锚点校验失败时的异常定位建议。
  - 可行时返回：`feasible: true`、`remove_rows`（建议剔除的输入行号，1 起）、`kept`（保留锚点）、`removed`（逐行剔除原因）、`preview`（用保留锚点得到的校准预览，结构同 `/api/preview`）或 `preview_error`（SRT 无法解析时）。
  - 不可行时返回：`feasible: false` 与 `reason`（无法预演原因）。
- `POST /api/export` — 同 `/api/preview` 请求体；无问题时返回 `calibrated.srt` 文件下载，有问题返回 `400`。
- `POST /api/clip/preview` — 请求体 `{"srt": "...", "ranges": [{"start": "00:00:00,000", "end": "00:00:05,000"}, ...]}`，返回 `entry_count`、`total_duration`（保留区间总时长，毫秒）与 `entries`（字段：`index` 新序号、`src_index` 原序号、`range_row` 命中的输入区间行号、`new` 剪辑后时间行、`text` 正文）。区间起点不早于终点、区间重叠、缺少区间或 SRT 无法解析时返回 `400`，`detail` 为错误文本。
- `POST /api/clip/export` — 同 `/api/clip/preview` 请求体；校验通过后返回 `clipped.srt` 文件下载（连续重编号），校验失败返回 `400`。
